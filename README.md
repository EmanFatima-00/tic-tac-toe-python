# Tic Tac Toe Game - Python

A simple and interactive console-based Tic Tac Toe game built using Python.

### Features
- 2-player gameplay
- Interactive game board
- Winning condition logic
- Input validation
- Play again option

### Tech Stack
- Python
- Functions and conditional statements
- Console-based logic

### How to Run
1. Clone this repository:
   git clone https://github.com/EmanFatima-00/tic-tac-toe-python.git

2. Run the Python file:
   python tic_tac_toe.py
